# 烟踪智治 · AI 烟头识别与环卫调度平台（管理员端）

> 基于设计稿复现的 18 个页面，正在组装为一个可交互的前端产品。
> 当前阶段：**纯前端 UI 交互**，不接后端真实数据。

---

## 一、产品定位与设计思路

本平台基于**优漏检测（异常检测）能力**，针对**烟头乱扔行为**进行 AI 识别：
当有人将烟头扔在地上时，摄像头 + AI 自动识别、取证、上报。

本项目做的是**管理员端（区域治理端）**，核心任务：

1. **触发频率分析**：统计各区域烟头乱扔的触发频率（扔烟头频率高的地点）
2. **热力图标记**：在全域地图上对高频触发点做热力图渲染，直观呈现治理重点
3. **全域地图**：平台核心展示层，后续需接入 **MCP 地图服务**（见 §5.1）
4. **数据汇总**：当前为复现阶段，页面中的数据是演示用静态数据；
   真实验证阶段的实际数据量远小于页面展示值，先保持原样
5. **AI 治理**：后续根据**推荐方案**进行，会接入**智能体（Agent）**做问题回答，
   前端需预留接口（见 §5.2）

> 当前首要任务：顶部标题栏下拉已完成 v4 重设计（见 §四 修复记录），接下来是各页面按钮反馈打磨 + 信息同步按钮填充。

## 三、导航体系

```
一级导航（顶部标题栏，全站统一，点击/悬停弹出下拉）
├── 态势总览      → 事件总览(2) / 治理态势(3) / 设备状态(4) / 工作看板(5)
├── 事件中心      → 告警中心(6) / 事件报表(7)
├── 调度中心      → 任务池(8) / 调度记录(9)
├── 全域地图      → GIS 全屏地图(10)
├── 资源管理      → 设备资源(11) / 环卫资源(12)
├── AI治理        → 模型与数据集(13) / AI识别配置(14) / 数据分析(15)
└── 系统管理      → 权限与账号(16) / 系统配置(17) / 审计日志(18)
```

- 下拉样式全站统一为 v4 悬浮卡片菜单（圆角卡片 + 箭头锚点 + 模块名头部 + 图标行 + 「当前」徽标，见 §四 v4 修复记录）
- 当前所在子页面在下拉中高亮（selected）
- 页面内还保留二级菜单条（总览菜单 / AI菜单 / 事件菜单 / 调度菜单等），同样可跨页跳转
- 点击空白处或 `Esc` 关闭下拉

## 四、当前已实现的 UI 交互

| 交互 | 说明 |
|------|------|
| 登录进入 | 页面 1 点击「安全登录」/ 回车 → 直接进入项目总览（暂不做校验） |
| 顶部导航下拉 | 全站 7 个模块，**点击 = 钉住展开**，再点 / 点空白 / 点内容区(iframe) / Esc 收起；**悬停 = 临时预览**；点击子项切换后立即收起；当前页在面板中带「当前」徽标 |
| 二级菜单跳转 | 页面内菜单条（事件总览/AI菜单等）跨页跳转 |
| 按钮反馈 | 查询/重置/导出/导入/保存/删除/派发/改派/标记/预览/编辑/启禁用等 → toast 提示 |

**v4（2026-09-16）下拉面板重设计 + 残留浮层清理**

用户反馈：切换页面时仍有「下拉按钮」样式的白色方块突兀地浮在内容上（附 3 张截图）。实测定位出三类来源，全部修复：

   参照 Ant Design / Element 的菜单形态重做为「悬浮卡片菜单」：
   - 圆角 14px 卡片 + 大柔和投影 + 顶部小箭头锚点（对准触发它的导航项，随面板居中移动）

   - 当前页 = 青色渐变选中态 + 「当前」徽标

2. **切换行为**：点击子项切换子页后下拉**立即收起**（v3 的「钉住不收」改为收起，避免遮挡内容）；
